## v1.0.90 修复筛选下拉 placeholder 不显示（塌陷根因定位）
- 需求原文（第二次反馈）：「所有的筛选项中，不要显示为空，全部显示：请选择」——v1.0.86 只补了 placeholder 文本未解决渲染
- **根因（headless Edge 实测 + 源码确认）**：EP 组件样式经 unplugin/style-import 按组件后加载，晚于 main.ts 的 styles/index.scss（内含 tailwind），同权重下 EP 的 `.el-select{width:100%}` 覆盖 Tailwind 非 important 宽度类（w-[140px] 等）；在 el-form inline 收缩容器中 width:100% 循环依赖退化为 auto，而新 select 的 placeholder 是 absolute 定位不占宽、selection 是 flex:1 1 0%，整体 min-content 塌陷为 44px（仅 caret+padding），placeholder width:100%×0 → 不可见
- **修复**：① element.scss 在 :root 内给 .el-select 加 min-width:100px 兜底（min-width 不受加载顺序影响）；② 6 个文件 11 处筛选 el-select 的 class="w-[Npx]" 批量加 ! 前缀恢复设计宽度（consumer/lists 1、order/nursing 2、order/meal 2、order/helper 1、order/evaluate 2、order/escort 3；node 脚本计数校验 11/11 全中）
- **验证**：headless Edge 重跑 /order/escort，三个筛选 placeholder rect.w 从 0 → 96/76/86（=140/120/130 减去 padding），文本「请选择」灰色可见；vite build ✓ built in 56.54s
- 教训：本项目给 EP 组件写 Tailwind 宽度类必须用 ! 前缀（或依赖 min-width 兜底）；对话框水平表单不塌陷（content 宽度确定），仅 el-form inline 筛选栏受影响
- 诊断脚本沉淀在 workspace：.tmp-select-check.mjs（playwright-core + headless Edge channel msedge，admin/admin 登录）
